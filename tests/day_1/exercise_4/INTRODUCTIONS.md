# Day 1 – Exercise 4: I'm a Logging Jack (and I'm Okay)

## Goals
- Understand how logging works in combination with Playwright
- Learn how logs can help debug and understand test execution

## Instructions
    1. Copy the code from `exercise_2.spec.ts` into `exercise_4.spec.ts`
    2. Add logging to each major test step, for example:
      - Navigation
      - Clicking elements
      - Assertions
      - Screenshot creation
    3. Run the test
    4. Observe the logs in the test output / report

You may use:
- `console.log`
- `test.step`
- or a combination of both

## Definition of Done
    - The test runs successfully
    - Logs clearly describe what the test is doing
    - Logs appear in the test output or Playwright report
